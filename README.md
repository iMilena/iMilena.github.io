# Portfólio de Milena Calasans

Site no ar: https://imilena.github.io

Portfólio de inteligência de processos, automação, agentes de IA e blockchain.

## Como o site está organizado

O site inteiro fica em um único arquivo, `index.html`, com HTML, CSS e JavaScript juntos. As páginas são navegadas pelo endereço com `#/`:

- `#/` Início
- `#/projetos` Projetos
- `#/sobre` Sobre mim
- `#/contato` Contato

## Como atualizar

Edite o `index.html`, faça commit na branch `main` e o GitHub Pages publica sozinho em cerca de 1 minuto.
